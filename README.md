# Veljko Radivojević — Portfolio 2026

My personal portfolio. I came from marketing — three years at Fortrade building landing pages and email campaigns. Somewhere along the way the code got more interesting than the copy, so I switched.

**Live:** https://veljko-portfolio-2026.vercel.app

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- EmailJS
- Lucide React
- react-hook-form

---

## Run locally

```bash
npm install
npm run dev
```
